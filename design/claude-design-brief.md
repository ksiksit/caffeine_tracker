# captest1 디자인 브리프

> claude.ai/design 프로젝트를 새로 시작할 때 **이 문서 전체를 첫 프롬프트에 붙여넣는다.**
> 값은 전부 앱 소스(`feat/client-server-phase1`)와 `design/*.dc.html` 아트보드에서 추출한 실제 값이다.
> 아트보드 원본: 이 폴더의 `*.dc.html` · 캔버스 링크는 `docs/feature-roadmap.md` §7.

## 앱

질 좋은 수면을 위한 카페인 관리 iOS 앱. 마신 카페인을 기록하면 약동학 모델로 체내 잔류량과 취침 시
예상 잔량을 계산해 "오늘 언제까지 마셔도 되는지"를 알려주고, HealthKit 수면 기록으로 개인 반감기를
학습한다. SwiftUI · 탭 4개(홈 · 수면 분석 · 내 학습 · 설정) + 카페인 추가 모달 시트.

## 간격과 형태

- 화면 좌우 여백 16 · 상하 16 · 카드 사이 16
- 카드: radius 12(continuous), padding 16, 내부 간격 12
- 리스트 행: 상하 10, 아이콘–텍스트 간격 12, 구분선 좌측 인셋 44
- 아이콘 뱃지: 채운 원 ⌀28(기본) / 32(리스트) / 36(프리셋), 심볼 크기 = 지름 × 0.54
- 신호등 원: ⌀240, 세로 그라디언트, 같은 색 50% 글로우(CSS blur 32)
- 기본 버튼: 높이 56, radius 12, 브랜드 브라운, 흰 17 semibold
- 최소 터치 영역 44 × 44
- 설정은 inset grouped 리스트: 카드 좌우 여백 20, 셀 내부 16, 섹션 헤더 좌 36, 카드 radius 10
- 프레임: iPhone Pro 402 × 874, 상단 안전영역 62, 탭바 49, 홈 인디케이터 34

## 컴포넌트

- **HealthCard** — 아이콘 뱃지 + 제목(17 semibold) + 내용. 흰 카드.
- **접히는 HealthCard** — 헤더 우측에 chevron(펼치면 90° 회전). **기본 접힘.**
- **HealthMetric** — 라벨 15 보조색 + 값 34 rounded bold + 단위 20 semibold 보조색. 보통 2개를 한 행에.
- **CategoryIconBadge** — 채운 원 안에 흰 심볼.
- **SectionHeader** — 13 semibold 보조색.
- **신호등 원** — 앞면은 심볼 30 + 상태 텍스트, 탭하면 뒤집혀 잔류량 · 취침 예상 · 총 섭취 3개.
- **탭바** — 4탭, 아이콘 26 + 라벨 10.
- **아이콘** — SF Symbols를 24 그리드 인라인 SVG로 대체. `.fill` 심볼은 면, 나머지는 선 — 굵기 1.7(본문) /
  2.2~2.4(chevron · 체크 · 엑스) / 2.6(신호등 원 안).

| 탭 | 구성 |

| 홈 | 신호등 원(탭 → 뒤집기) · 카페인 추가 버튼 · 시간대별 카페인 차트(기본 접힘) · 오늘의 기록 |

| 내 학습 | 현재 추정 반감기 hero · "학습 상세 보기"(기본 접힘) 안에 추세 · 모델 정확도 산점도 · 입력 분포 · 전체 기록 |
| 설정 | 카페인 대사 · 개인화 학습 · 수면 · 건강 데이터 · 알림 · 계정 · 정보 |
| 카페인 추가 | 모달 시트. 상단 즉시 미리보기 배너 + 프리셋 7종 2열 그리드 + 직접 입력 |

**상태 분기** — 신호등 5가지(지금 OK / 마감 시각 / 곧 마감 / 지금은 패스 / 오늘은 NO),
학습 3가지(관측 0회 / 1~2회 / 3회 이상), 수면 3가지(권한 요청 / 데이터 없음 / 정상).

## 목업에 쓸 숫자

화면끼리 어긋나지 않도록 하나의 시나리오를 쓴다.

```
오전 8:00 아메리카노 150mg · 오전 10:30 녹차 30mg
지금 오후 1:00 · 취침 23:00 · 반감기 5.0h · 기준 섭취량 75mg
```

여기서 나오는 값(전부 실제 계산값): 마감 **오후 3:20** · 현재 잔류 **96mg** · 취침 예상 **24mg** ·
총 **180 / 400mg** · 지난밤 **6시간 52분**, 침대에서 7시간 34분, 효율 90%, SOL 26분 ·
학습 **7회 관측 → 5.57h** (95% CI 5.11~6.03, 신뢰도 68%, R² 0.729, RMSE 3.2분)

공식: `amount = dose × e^(−ln2 / T½ × t)`. 다른 숫자를 쓸 거면 이 식으로 다시 계산할 것.

## 지어내면 안 되는 값

- 음료 프리셋 7종: 아메리카노 150 · 에스프레소 75 · 라떼 150 · 녹차 30 · 홍차 50 · 콜라 35 · 에너지드링크 80 (mg)
- 건강 상태 배수: 없음 1.0 · 흡연 0.5 · 경구피임약 2.0 · 임신 2.5
- 취침 안전선 50mg · 일일 권장 400mg · 기본 반감기 5.0h(3.0~7.0)
- UI 텍스트는 전부 한국어
- 가짜 iOS 상태바(9:41 · 배터리 · 와이파이)는 그리지 않는다 — 실기기에서 시스템이 그린다

## 알려진 문제 — 그대로 재현하지 말 것

현행 화면을 충실히 옮기면 아래도 같이 따라온다. 새로 디자인할 때는 고쳐서 그린다.
(상세는 `docs/feature-roadmap.md` §2 (19)~(23))

1. `.safeAnytime`("지금 OK")이 기본 설정에서 도달 불가 — 안전선 50mg < 기준 섭취량 75mg이라 조건이 성립하지 않는다.
2. 차트의 취침 후 붉은 위험 영역이 하루 전체 최대 잔량 기준이라, 취침 시 잔량이 안전해도 칠해진다.
3. 수면 탭 배경이 정상 상태에만 지정돼 있어 빈 상태 두 개만 흰 배경이다.
4. 카페인 추가의 미리보기 배너 배경이 시트 배경과 같은 값이라 면이 보이지 않는다.
5. 앱 아이콘 이미지가 없다.

## 붙여넣는 순서

1. claude.ai/design에서 프로젝트를 새로 만든다.
2. 이 문서 전체를 첫 프롬프트에 붙여넣고, 만들 화면을 지정한다.
   예: "홈 화면부터. 신호등은 마감 시각 상태로."
3. 참고 이미지가 필요하면 캔버스 툴바 Export로 아트보드 PNG를 뽑아 첨부한다.
   토큰 시트 1장 + 대상 화면 1장이면 충분하다.
