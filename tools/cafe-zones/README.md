# 카페 구역 데이터 (`captest1/Resources/CafeZones.json`)

카페 근처 알림이 감시할 전국 카페 구역. 앱은 사용자가 고른 동(최대 2개)의 구역을 합쳐 카페 수 상위 17개를 지오펜스로 등록한다.
원본 데이터와 위치는 서버로 가지 않는다.

## 다시 만들기

```bash
# 원본: 소상공인시장진흥공단 상가(상권)정보 zip (약 340MB, 레포에 넣지 않음). 기본 경로는 ../data-check/raw/
python3 tools/cafe-zones/build_zones.py --raw <zip 또는 폴더>
python3 tools/cafe-zones/check_zones.py
```

표준 라이브러리만 쓴다(numpy·pandas 불필요). 전국 약 15초.

## 규칙

| 단계 | 규칙 |
|---|---|
| 업종 | 소분류코드 `I21201`(카페)만. 스터디카페 `R10202` 제외 |
| 정제 | 국내 범위 밖 좌표 제거. 같은 행정동에서 (위도, 경도)가 같은 행은 하나로 (양재2동 126 → 107) |
| 묶기 | 행정동마다 반경 상한 150m: 남은 카페 중 150m 안 이웃이 가장 많은 카페를 중심으로 원을 떼어내기 반복. 동률이면 (위도, 경도)가 작은 쪽 |
| 자르기 | 동마다 카페 수 내림차순 상위 17구역 (iOS 앱당 감시 구역 20개 중 3자리는 예비) |

## 검증 (`check_zones.py`)

- 골든: `fixtures/`의 양재2동 원본을 같은 함수로 묶어, 탐색 분석 결과(지오펜스 시험 앱이 쓴 값)와 카페 107곳·25구역·카페 수 순서·상위 3구역 중심(1m 이내)이 같은지.
  카페 수가 같은 하위 구역은 동률 처리에 따라 중심이 달라질 수 있어 비교하지 않는다.
- 번들: 스키마, 동 3,400개 이상, 동마다 17구역 이하·카페 수 내림차순, 좌표 국내 범위, 4MB 이하, 양재2동 = 골든 상위 17개.
